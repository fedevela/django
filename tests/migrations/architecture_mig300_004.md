# MIG-300-004 Architecture Artifact

## Requirement-to-architecture map

- `MIG-300-004 / AC1`: Repeated autogeneration under locale A → B → A emits stable enum-default text (`EnumClass['MEMBER']`) for equivalent model defaults.
- `MIG-300-004 / AC2`: Deconstruction and reconstruction with locale-sensitive enum values does not alternate between member-index and value forms.

## Ownership and boundaries

- Owner: `django/db/migrations/serializer.py:EnumSerializer.serialize`.
- Responsibility: represent enum defaults by name-index form and avoid locale-derived values in emitted source.
- Owner: `django/db/migrations/serializer.py:DeconstructableSerializer.serialize_deconstructed`.
- Responsibility: deterministic deconstruction path contract from `(path, args, kwargs)` to serializable code fragments.
- Owner: `django/db/migrations/serializer.py:serializer_factory`.
- Responsibility: stable serializer selection for any object entering migration serialization, including enum members and lazy/promised values.
- Owner: `django/db/migrations/writer.py:MigrationWriter.serialize`.
- Responsibility: canonical handoff point from domain objects to serialization boundary.
- Owner: `django/db/migrations/writer.py:MigrationWriter.as_string`.
- Responsibility: serialize operations/imports to migration source with stable ordering and locale-independent content.
- Owner: `tests/migrations/test_writer_enum_default_contracts.py::MigrationWriterEnumDefaultDeterminismContractsTests`.
- Responsibility: contract surface to capture deterministic behavior obligation for future implementation.
- Owner: `tests/migrations/traceability_mapping_mig300_004.md`.
- Responsibility: traceability record tying requirements, contracts, and loci.

## Contract artifacts (source shape)

- Serialization contract:
  - `MigrationWriter.serialize(value)` delegates to `serializer_factory(value).serialize()`.
  - Return type contract: `(source_text: str, imports: set[str])`.
- Deconstruction contract:
  - `DeconstructableSerializer.serialize_deconstructed(path, args, kwargs)` accepts the `deconstruct` tuple and emits `"module.Symbol(args...)"`.
- Enum-default contract:
  - `EnumSerializer.serialize` emits `"<module>.<EnumClass>[\"MEMBER\"]"` (or single-quoted equivalent) with an `import <module>` side-effect.
- Emission contract:
  - `MigrationWriter.as_string` consumes serialized operation fragments and emits a migration module body plus import block deterministically.

## Architecture pressure → placement

- Determinism pressure (AC1):
  - Mapping point: `EnumSerializer.serialize` owns the canonical token choice and blocks value-based emission.
- Reconstruction consistency pressure (AC2):
  - Mapping point: `serialize_deconstructed` owns ordered kwargs and argument serialization independent of process locale.
- Stability pressure across repeated runs:
  - Mapping point: `MigrationWriter.serialize` and `MigrationWriter.as_string` own deterministic seams that must not inject locale.
- Cross-run and import boundary pressure:
  - Mapping point: migration module execution boundary (`MigrationWriter.as_string` output shape) is the integration seam used by future roundtrip tests.

## Dependency direction

- `writer.py` depends on `serializer.py` for every value conversion.
- `serializer.py` depends only on serializer primitives and model/manager/operation contracts in `django.db`.
- Tests consume writer/serializer contracts but do not participate in runtime serialization control flow.
- Traces consume test and implementation artifacts; they do not influence runtime behavior.

## Integration seams and stubs

- Primary seam: `MigrationWriter.serialize -> serializer_factory`.
- Primary seam: `serializer_factory -> serializer dispatch table`.
- Primary seam: `Serializer.serialize output -> MigrationWriter.as_string`.
- Secondary seam: migration execution boundary (`migration_text` generated by `as_string` -> executed/imported in downstream migration runner).
- Placeholder implementation stubs are already present as contract-only tests in `MigrationWriterEnumDefaultDeterminismContractsTests`.
